## NHN Cloud > 商標ガイド > 概要 { #nhn-cloud-trademark-guide-overview }

NHN Cloud の商標とは、NHN Cloud の商品およびサービスを表し、他社の商品やサービスと区別するために採用・使用する単語、サービス名、ロゴとシンボル、およびすべてのデザインの総体を意味します。
本ガイドラインでは、NHN Cloud の商標が不適切に使用されることで当社のブランド価値が損なわれたり希薄化されたりしないよう、NHN Cloud メンバーおよび NHN Cloud パートナーに対して、正しい商標使用の指針を提示します。
本ガイドラインで取り上げていない項目についてご不明な点がある場合は、[カスタマーセンター](https://www.toast.com/kr/support/inquiry)までお問い合わせください。
<br>

<a id="the-nhn-cloud-trademark-may-only-be-used-by-nhn-cloud-members-and-nhn-cloud-partners"></a>
### 1. NHN Cloudの商標は、NHN Cloudの会員およびNHN Cloudパートナーに限り使用できます。 { #the-nhn-cloud-trademark-may-only-be-used-by-nhn-cloud-members-and-nhn-cloud-partners }

<a id="the-nhn-cloud-trademark-may-only-be-used-by-nhn-cloud-members-and-nhn-cloud-partners-member"></a>
#### 会員

- NHN Cloud会員とは、NHN Cloudとサービス利用契約を締結し、サービス利用資格を付与された個人または法人を指します。
- NHN Cloud会員は、以下の用途に限りNHN Cloudの商標を使用できます。
    - NHN Cloud会員がNHN Cloudのサービスを使用していることを証明するための用途
    - NHN Cloudのサービスが使用されたサービスやコンテンツを識別または宣伝するための用途
- NHN Cloudのサービスの使用を停止した場合、またはNHN Cloud会員を退会した場合は、NHN Cloudの商標の使用を直ちに停止する必要があります。

<a id="the-nhn-cloud-trademark-may-only-be-used-by-nhn-cloud-members-and-nhn-cloud-partners-partner"></a>
#### パート

- NHN Cloud パートナーとは、NHN Cloud の会員であり、NHN Cloud とパートナー契約を締結して NHN Cloud サービスをリセリングする事業者を意味します。
- NHN Cloud パートナーは、以下の用途に限り NHN Cloud の商標を使用できます。
    - NHN Cloud のパートナーであることを証明するための用途
    - NHN Cloud 会員に NHN Cloud サービスをリセリングするためのマーケティング用途
- パートナー契約が終了または解除された場合は、NHN Cloud 商標の使用を直ちに中止する必要があります。
<br>

<a id="nhn-cloud-members-and-nhn-cloud-partners-must-comply-with-the-following-requirements"></a>
### 2. NHN Cloud 会員および NHN Cloud パートナーは、以下の事項を遵守しなければなりません。 { #nhn-cloud-members-and-nhn-cloud-partners-must-comply-with-the-following-requirements }

<a id="nhn-cloud-members-and-nhn-cloud-partners-must-comply-with-the-following-requirements-correct-trademark-usage"></a>
#### 正しい商標の使用方法

- 適切な場所に適切な商標を表示し、適切な権利帰属文言を使用する必要があります。
- 当社の商標には ™ を付けて、商標として使用していることが分かるように表記する必要があります。
- 当社のいかなる商標も、貴社の商標、サービスマーク、ドメイン名、製品名またはロゴとして使用しないでください。
- 当社の商標を変形もしくは略語で使用したり、他の商標と結合または組み合わせて使用しないでください。

<a id="nhn-cloud-members-and-nhn-cloud-partners-must-comply-with-the-following-requirements-trademark-use-is-prohibited"></a>
#### 商標の使用が禁止される行為

- 当社の商標を模倣または偽造して、当社の商標と混同される可能性のある類似の商標を使用しないでください。
- 当社の商標を i) 普通名詞として使用したり、ii) 違法なコンテンツを提供する商品またはサービスに使用したり、iii) その他法律に違反する商品またはサービスに表示したりしないでください。
- 当社との経営上・組織上・財務上または契約上の関連があるかのように誤解を招く形で商標を表示しないでください。
