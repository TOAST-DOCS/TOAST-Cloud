## NHN Cloud 会員登録 { #join-nhn-cloud }

<a id="how-to-join-as-member"></a>
### 会員登録の手順 { #how-to-join-as-member }
https://nhncloud.com にアクセスし、画面右上の **会員登録** ボタンを押します。
会員登録の手順は以下のとおりです。
![userguide_01_20210401](https://static.toastoven.net/toast/user_guide/userguide_01_20210401.png)


<a id="how-to-join-as-member-select-country"></a>
#### 国の選択
NHN Cloud の会員は、登録時に選択した国に応じて、韓国会員 (NHN Cloud) と日本会員 (NHN Cloud Japan) に区分されます。
各国の法令に基づく NHN Cloud 利用規約および個人情報処理方針に同意した場合にのみ、会員として登録できます。

- 韓国会員 (NHN Cloud)
    - 登録時に「韓国」を選択した会員

- 日本会員 (NHN Cloud Japan)
    - 登録時に「日本」を選択した会員

<a id="how-to-join-as-member-select-type-of-membership-individualbusiness"></a>
#### 会員種別（個人/事業者）の選択
会員種別ごとに、登録時に必要な事項は以下のとおりです。
事業者会員は、登録時に「韓国または日本」を国として選択した場合にのみ登録できます。

- 個人会員
    - メール受信可能なメールアドレス
    - SMS 確認可能な携帯電話
- 事業者会員
    - メール受信可能なメールアドレス
    - SMS 確認可能な携帯電話
    - 事業者登録証のコピー（登録時に韓国を選択した事業者会員のみ）

<a id="login-security-settings"></a>
### ログインセキュリティ設定 { #login-security-settings }
ログインセキュリティ設定では、2 段階ログインの設定が可能です。
「メール認証、携帯電話認証、Google OTP 認証」をサポートしています。

<a id="login-security-settings-select-login-security-settings"></a>
#### ログインセキュリティ設定の選択
![userguide_02_20230330](https://static.toastoven.net/toast/user_guide/userguide_10_202303.png)
サインイン後、ホームページ右上のサインインアカウントをクリックすると表示されるドロップダウンメニューから **ログインセキュリティ設定** を選択します。
現在のログインセキュリティ設定を確認でき、「変更」ボタンを押して変更できます。

- 2 段階ログイン設定
    - 2 段階ログイン設定なし: 初期状態で、2 段階ログインセキュリティ設定を使用しない状態
    - メールまたは携帯電話で認証後にログイン: ログイン時に会員情報のメールアドレスまたは携帯電話番号に認証番号を受け取って認証
    - Google OTP 認証後にログイン: ログイン時に Google OTP アプリで認証

<a id="login-security-settings-log-in-after-google-otp-verification"></a>
#### Google OTP 認証後のログイン設定方法
2 段階ログイン設定で「Google OTP 認証後にログイン」を選択し、「保存」ボタンを押します。
OTP 認証設定を順番に進めます。

1. OTP 認証アプリをインストールします。
![userguide_03_20230330](https://static.toastoven.net/toast/user_guide/userguide_11_202303.png)

2. OTP 認証アプリに NHN Cloud アカウントを追加します。
![userguide_04_20230330](https://static.toastoven.net/toast/user_guide/userguide_12_202303.png)

3. OTP 認証アプリの画面に表示された NHN Cloud アカウントの認証番号を入力します。
![userguide_05_20230330](https://static.toastoven.net/toast/user_guide/userguide_13_202303.png)

4. OTP 登録デバイス名を入力します。（ひらがな・カタカナ・漢字、英字、日本語、中国語、スペース、数字のみ入力可能 / 最大 10 文字）
![userguide_06_20230330](https://static.toastoven.net/toast/user_guide/userguide_14_202303.png)

OTP 認証設定が完了すると、OTP 認証デバイスリストに登録されたデバイスが表示されます。
![userguide_07_20230330](https://static.toastoven.net/toast/user_guide/userguide_15_202303.png)

- 登録基準
    - 最大 5 台まで登録可能
- 削除基準
    - OTP 認証デバイスが 2 台以上の場合: OTP 認証デバイスを削除可能
    - OTP 認証デバイスが 1 台の場合: OTP 認証デバイスを追加するか、2 段階ログイン設定を変更しないと削除できません

## 決済手段の登録 { #register-payment-methods }
NHN Cloud サービスを利用するには、決済手段を登録する必要があります。
ただし、メンバーとして招待されている組織またはプロジェクトがある場合は、決済手段を登録しなくても NHN Cloud サービスを利用できます。

決済手段の登録は、サインイン後にホームページ右上のサインインアカウントをクリックすると表示されるドロップダウンメニューから **決済手段** を選択して進めることができます。
NHN Cloud で提供する決済手段は以下のとおりです。
ただし、会員登録時に選択した国によって使用できる決済手段が異なります。

- 韓国
    - 個人: PAYCO クレジットカード、クレジットカード
    - 事業者: PAYCO クレジットカード、クレジットカード、口座振替
- 日本
    - 個人: クレジットカード
    - 事業者: クレジットカード

|--------|--------|--------|---|------|---|

|  |  | クレジットカード | 携帯電話本人認証 | カード番号、有効期間、生年月日 | 個人/記名式法人カード対応 |
|  | 事業者 | PAYCO クレジットカード | 住民登録番号または事業者登録番号 | カード番号、有効期間 | カード有効性検証のため 1,000 ウォン決済後に取消処理 |
|  |  | クレジットカード（記名） | 携帯電話本人認証 | カード番号、有効期間、生年月日 |  |
|  |  | クレジットカード（無記名） | 事業者登録番号 | カード番号、有効期間、パスワード前 2 桁 | |
|  |  | 口座振替 | 電子証明書認証 | 銀行、口座番号 | 個人口座は個人の電子証明書 <br/> 法人口座は会員/法人口座/電子証明書の事業者情報が一致している必要があります |
| 日本 | 個人 | クレジットカード | カード所有認証 | カード番号、有効期間、名前、セキュリティコード | カード有効性検証のため 2 円決済後に取消処理 |
|  | 事業者 | クレジットカード | カード所有認証 | カード番号、有効期間、名前、セキュリティコード | カード有効性検証のため 2 円決済後に取消処理 |

<a id="manage-credits"></a>
## クレジットの管理 { #manage-credits }
NHN Cloud サービスで管理するクレジットは、サービス加入、リワード、イベント、補償を目的として無償で付与するクレジットです。
クレジットは現金 1 ウォンと同等です。
付与されたクレジットは、サインイン後にホームページ右上のサインインアカウントをクリックすると表示されるドロップダウンメニューから **クレジット** を選択して確認できます。
クレジットは以下のポリシーで運営されます。

- 返金されません。
- 有効期間を管理します。有効期間を過ぎると消滅し、積立タイプごとに柔軟に運営します。
- クレジットの付与は、決済手段を登録した一部の国の会員に提供されます。
- クレジットは携帯電話番号・事業者番号につき 1 つのみ使用でき、会員が NHN Cloud 運営ポリシーに違反する行為を行った場合、クレジットを回収することがあります。
- NHN Cloud の利用料金が発生した際にクレジットがある場合、自動的にクレジット分の利用料金が差し引かれます。
- NHN Cloud の利用料金が保有クレジットを超える場合、クレジットから差し引いた後、残りの金額が有料課金されます。
- 登録記念クレジットは、NHN Cloud が提供するサービスの料金支払いに利用できます。
    - 除外サービス: Notification、GPU Instance、マーケットプレイス、別途お問い合わせサービスを除く

<a id="withdraw-from-membership"></a>
## 会員退会 { #withdraw-from-membership }
<a id="apply-for-membership-withdrawal"></a>
### 会員退会の申請 { #apply-for-membership-withdrawal }
NHN Cloud の会員退会は、サインイン後にホームページ右上のサインインアカウントをクリックすると表示されるドロップダウンメニューから **会員情報** を選択して申請できます。
**会員情報** 画面に移動し、右下の **会員退会** ボタンを押します。
会員退会の注意事項を確認後、**会員退会** をクリックします。
利用中のサービスがある場合は、会員退会を申請できません。

<a id="verify-membership-withdrawal"></a>
### 会員退会の検証 { #verify-membership-withdrawal }
会員退会申請後、以下の情報を確認し、退会処理を行います。<br/>
利用料金が残っている場合、自動決済日（毎月 8 日）に決済が完了した後に退会処理されます。

<a id="complete-membership-withdrawal"></a>
### 会員退会の完了 { #complete-membership-withdrawal }
会員退会が完了すると、退会申請時に登録したメールアドレスに退会内容が送信されます。
会員退会時にすべての利用情報が削除され、削除されたデータは復元されません。
