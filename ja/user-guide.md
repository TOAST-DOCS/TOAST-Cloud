## NHN Cloud 会員登録

<a id="how-to-join-as-member"></a>

### 会員登録の手順
https://nhncloud.com にアクセスし、画面右上の **[会員登録]** をクリックします。
会員登録の手順は以下のとおりです。
![userguide_01_20210401](https://static.toastoven.net/toast/user_guide/userguide_01_20210401.png)


<a id="select-country"></a>

#### 国の選択
NHN Cloudの会員は、会員登録時に選択した国に応じて、韓国会員（NHN Cloud）と日本会員（NHN Cloud Japan）に区分されます。
各国の法令に基づくNHN Cloudの利用規約およびプライバシーポリシーに同意した場合にのみ、会員として登録できます。

- 韓国会員（NHN Cloud）
    - 会員登録時に「韓国」を選択した会員

- 日本会員（NHN Cloud Japan）
    - 会員登録時に「日本」を選択した会員

<a id="select-type-of-membership-individualbusiness"></a>

#### 会員タイプ（個人/法人）の選択
会員タイプに応じて、登録時に必要な事項は以下のとおりです。
法人会員は、会員登録時に「韓国または日本」の国を選択した場合にのみ登録できます。

- 個人会員
    - メールを受信できるメールアドレス
    - SMSを受信できる携帯電話番号
- 法人会員
    - メールを受信できるメールアドレス
    - SMSを受信できる携帯電話番号
    - 事業者登録証のコピー（登録時に韓国を選択した法人会員のみ対象）

<a id="login-security-settings"></a>

### ログインセキュリティ設定
ログインセキュリティ設定では、2段階ログインの設定が可能です。
「メール認証、携帯電話認証、Google OTP認証」をサポートしています。

<a id="select-login-security-settings"></a>

#### ログインセキュリティ設定の選択
![userguide_02_20230330](https://static.toastoven.net/toast/user_guide/userguide_10_202303.png)
ログイン後、Webサイト右上のログインアカウントをクリックすると表示されるドロップダウンメニューから **[ログインセキュリティ設定]** を選択します。
使用中のログインセキュリティ設定を確認でき、「変更」ボタンをクリックして変更できます。

- 2段階ログイン設定
    - 2段階ログイン設定なし：初期状態として、2段階ログインセキュリティ設定を使用しない状態
    - メールまたは携帯電話で認証後にログイン：ログイン時に会員情報のメールアドレスまたは携帯電話番号に認証番号を受け取り認証
    - Google OTP認証後にログイン：ログイン時にGoogle OTPアプリで認証

<a id="log-in-after-google-otp-verification"></a>

#### Google OTP認証後にログインする設定方法
2段階ログイン設定でGoogle OTP認証後にログインを選択し、「保存」ボタンをクリックします。
OTP認証設定を順番に進めます。

1. OTP認証アプリをインストールします。
![userguide_03_20230330](https://static.toastoven.net/toast/user_guide/userguide_11_202303.png)

![userguide_04_20230330](https://static.toastoven.net/toast/user_guide/userguide_12_202303.png)

3. OTP認証アプリの画面に表示されたNHN Cloudアカウントの認証番号を入力します。
![userguide_05_20230330](https://static.toastoven.net/toast/user_guide/userguide_13_202303.png)

4. OTP登録デバイス名を入力します。（日本語、英語、韓国語、中国語、スペース、数字のみ入力可能 / 最大10文字）
![userguide_06_20230330](https://static.toastoven.net/toast/user_guide/userguide_14_202303.png)

![userguide_07_20230330](https://static.toastoven.net/toast/user_guide/userguide_15_202303.png)

- 登録基準
    - 最大5台まで登録可能
- 削除基準
    - OTP認証デバイスが2台以上の場合：OTP認証デバイスの削除が可能
    - OTP認証デバイスが1台の場合：OTP認証デバイスを追加するか、2段階ログイン設定を変更しないと削除できません

## 決済手段の登録
NHN Cloudサービスを利用するには、決済手段を登録する必要があります。
ただし、メンバーとして招待された組織またはプロジェクトがある場合は、決済手段の登録なしにNHN Cloudサービスを利用できます。

決済手段の登録は、ログイン後にWebサイト右上のログインアカウントをクリックすると表示されるドロップダウンメニューから **[決済手段]** を選択して進めることができます。
NHN Cloudが提供する決済手段は以下のとおりです。
ただし、会員登録時に選択した国によって使用可能な決済手段が異なります。

- 韓国
    - 個人：PAYCO クレジットカード、クレジットカード
    - 法人：PAYCO クレジットカード、クレジットカード、口座振替
- 日本
    - 個人：クレジットカード
    - 法人：クレジットカード

## 決済手段の登録方法

### PAYCO クレジットカード
<a id="select-payment-methods"></a>

#### 決済手段の選択
1. **[決済手段]** 画面で決済手段変更ボタンをクリックします。
2. **[自動決済手段登録]** 画面で **[PAYCOクレジットカード]** を選択します。

PAYCOのIDは、ご自身の携帯電話番号またはメールアドレスをIDとして使用できます。

1. 決済手段を初めて登録する際は、携帯電話による本人認証が行われます。
2. 本人認証後、決済手段の情報を入力し、同意手続きを経ると登録が完了します。
   決済手段の種類によっては、決済パスワードの入力が必要な場合があります。

#### PAYCOでの決済

## クレジットの管理
NHN Cloudサービスで管理するクレジットは、サービス加入、リワード、イベント、補償を目的として無償で付与するクレジットです。
クレジットは現金1ウォンと同等です。
付与されたクレジットは、ログイン後にWebサイト右上のログインアカウントをクリックすると表示されるドロップダウンメニューから **[クレジット]** を選択して確認できます。
クレジットは以下のポリシーで運用されます。

- 返金されません。
- 有効期限を管理します。有効期限を過ぎると消滅し、積立タイプ別に柔軟に運用されます。
- クレジットの付与は、決済手段を登録した一部の国の会員に提供されます。
- クレジットは携帯電話番号・事業者番号ごとに1つのみ使用でき、会員がNHN Cloudの運用ポリシーに違反する行為を行った場合、クレジットを回収することがあります。
- NHN Cloudのご利用料金が発生した場合、クレジットがあれば自動的にクレジット分の利用料金が差し引かれます。
- NHN Cloudのご利用料金が保有するクレジットを上回る場合、クレジットから差し引いた後、残りの金額が有料で課金されます。
- 会員登録記念クレジットは、NHN Cloudが提供するサービスの料金支払いに利用できます。
    - 対象外サービス：Notification、GPU Instance、マーケットプレイス、別途お問い合わせサービスを除く

## 退会
<a id="apply-for-membership-withdrawal"></a>

### 退会の申請
NHN Cloudの退会は、ログイン後にWebサイト右上のログインアカウントをクリックすると表示されるドロップダウンメニューから **[会員情報]** を選択して申請できます。
**[会員情報]** 画面に移動し、右下の **[退会]** ボタンをクリックします。
退会の注意事項を確認した後、**[退会]** をクリックします。
利用中のサービスがある場合は、退会を申請できません。

<a id="verify-membership-withdrawal"></a>

### 退会の検証
退会を申請した後、以下の情報を確認して退会を処理します。<br/>
未払いの利用料金がある場合は、自動決済日（毎月8日）に決済が完了した後、退会が処理されます。

<a id="complete-membership-withdrawal"></a>

### 退会の完了
退会が完了すると、退会申請時に登録したメールアドレスに退会内容が送信されます。
退会時にすべての利用情報が削除され、削除されたデータは復元されません。
